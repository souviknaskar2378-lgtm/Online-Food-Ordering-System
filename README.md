# Online-Food-Ordering-System
A responsive Online Food Ordering System built using HTML,CSS, and JavaScript with food search, category filtering, shopping cart, bill calculation, order form, and LocalStorage functionality
🍔 Online Food Ordering System

A modern, responsive and user-friendly Online Food Ordering System developed using HTML, CSS and JavaScript.

This project allows users to browse food items, search for dishes, filter food by category, add items to a shopping cart, manage quantities, calculate the total bill and place an order.

---

## 📌 Project Overview

The Online Food Ordering System is a front-end web application designed to provide a simple and convenient online food ordering experience.

Users can explore different food items, select their favourite dishes, add them to the cart and place an order by providing their delivery details.

The project demonstrates important JavaScript concepts such as DOM manipulation, event handling, arrays, objects, filtering, LocalStorage and form validation.

---

## ✨ Features

### 🍕 Food Menu

- Displays different food items
- Shows food name, category and price
- Attractive and responsive food cards

### 🔍 Search Food

- Search for food items by name
- Results update automatically while typing

### 📂 Category Filter

- Filter food by category
- Available categories include:
  - Pizza
  - Burger
  - Indian
  - Drinks

### 🛒 Shopping Cart

- Add food items to the cart
- Remove items from the cart
- Increase or decrease quantity
- Automatically updates cart item count

### 💰 Bill Calculation

- Automatically calculates subtotal
- Adds delivery charge
- Calculates final total amount

### 📝 Order Form

Users can enter:

- Full name
- Phone number
- Delivery address
- Payment method

### 💾 LocalStorage

- Cart information is stored using browser LocalStorage
- Cart remains available even after refreshing the page

### 📱 Responsive Design

- Works on desktop computers
- Works on mobile phones
- Works on tablets
